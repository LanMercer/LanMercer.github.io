紫微命盘改良与上线记录

实践人： LanMercer
实践项目： 紫微命盘（紫微斗数）
相关AI工具： DSH（DeepSeek Harness，记录中的编码模型为 deepseek-flash）、DeepSeek API
技术实现： Next.js、React、TypeScript、Tailwind CSS
上线平台： 魔搭创空间（ModelScope）
在线链接： 紫微命盘在线体验
GitHub仓库： LanMercer/ziwei-doushu
参考与改良基础： Renhuai123/ziwei-doushu

一、项目介绍

这次实践从一个 GitHub 开源紫微斗数项目开始。我希望把它变成适合自己使用的命盘工具：能够排盘，也能够借助自己的 AI 接口解释命盘，并在专业术语和通俗表达之间切换。

原项目提供了排盘算法、四化系统、格局知识库与古籍资料等基础。我在这个基础上做二次开发，重点改良 AI 解读、阅读体验、双人合盘和部署方式。排盘引擎的原始成果属于原作者，我的工作主要是接入服务与改进使用体验。

二、制作过程与AI分工

1. 先跑通开源项目，再补上解读

下载并在本地运行后，我发现开源版能排盘，但部分 AI 解读接口需要自行实现。

我选择接入自己的 DeepSeek API。DSH 协助阅读代码、设计接口、编写服务端请求和处理流式返回；我负责提出需求、运行项目、查看效果，并根据实际体验继续调整。

这里有两种不同的 AI 用法：DSH 帮我开发网页，DeepSeek API 为网页中的命盘解读提供文本生成能力。 排盘由程序完成，AI 根据排盘结果组织解释。

2. 从专业版扩展到通俗版

默认解读保留专业表达，方便查看命盘中的星曜、宫位和相关术语。考虑到阅读门槛，我又提出增加“简单版”：先生成专业版，再按需让 AI 将已有全文改写成容易理解的语言。

两种版本可以切换，通俗内容保留在当前页面中，减少重复请求。

3. 调整解读区域的阅读体验

连续提问会让页面不断变长，因此我将问答放进固定大小、内部滚动的解读框，并适当加宽阅读区域。

同时加入小、常规、大三档字体选择，让已有回答随字号设置一起变化。还清理了不适合个人版本的活动广告，并梳理本命、大限、流年等入口的交互，减少使用时的困惑。

4. 补充双人合盘与简单版

双人合盘最初提示缺少 AI 分析接口。我让 DSH 在现有开源基础上补充自己的合盘接口，使两人的排盘结果能够交给 AI 进行分析。

之后，双人合盘也增加了专业版与简单版切换：通俗版根据已有分析改写，生成失败可以重试；专业版尚未生成完毕时限制切换，避免只拿到半截内容就开始改写。

需要区分的是，自行接入 API 可以补充新的解读服务，但不会自动取得原作者未公开的商业系统、数据库或专有解读内容。

三、隐私与接口设计

隐私设计是先在本地解析命盘，再向 AI 发送解读需要的十二宫等结构化信息，减少原始身份信息的传递；同时移除 Vercel 统计组件调用。

API Key 由服务端环境变量读取，不写进公开页面。为了控制公开体验的调用成本，项目还加入访问口令、请求限流以及 Key 缺失时的提示。

本地排盘与在线 AI 解读的数据流不同：调用 DeepSeek API 时，相关解读输入仍会发送到该服务。 项目并非完全离线，本文不公开真实出生资料、API Key 或口令。

四、从本地运行到魔搭创空间

项目包含服务端 AI 接口，因此部署准备采用 Docker 方式保留 Node.js 运行环境，并配置平台需要的监听端口与环境变量。

部署时遇到依赖与 Dockerfile 版本不一致，以及镜像仓库登录返回 unauthorized 等问题，需要分别核对上传文件与平台构建日志。

本地源码、上传副本与平台文件需要保持一致，更新后也要检查网页实际效果。

目前的体验入口是：LanMercer 的紫微命盘创空间。较晚新增的双人合盘通俗版，以平台实际部署版本为准。

五、使用方式

  1. 打开上方魔搭创空间链接，进入应用。
  2. 按页面表单填写排盘信息，生成命盘。
  3. 在解读区域选择感兴趣的主题，查看流式生成的专业版内容；如页面要求口令，按提示输入。
  4. 想降低阅读难度时，切换到简单版，等待 AI 改写；也可以调整解读字号。
  5. 需要双人合盘时，填写两人的信息后生成分析，并按当前页面提供的选项查看专业版或简单版。

排盘可用而 AI 没有回答时，应区分口令、调用额度、API 配置与服务错误，按页面提示处理。

六、实践收获与项目说明

这次实践让我走完了“阅读开源项目 → 本地运行 → 接入自己的 AI → 根据体验修改交互 → 准备部署”的过程。AI 可以协助写代码和分析日志，而需求取舍、实际试用、隐私要求和最终验收仍需要我自己把关。

后续会继续核对线上版本，并完善不同设备下的阅读体验。

感谢原作者开放排盘引擎与相关资料。代码和资料的授权范围应分别遵守原仓库说明，二次开发也需要保留相应署名与许可。命盘与 AI 解读用于传统文化体验和项目学习，生成内容可能出错，不应作为现实决策的依据。
